# Baselarte

## Description

Baselarte is a minimalist software engineering project focused on building a simple, efficient and scalable web application.

The project combines frontend development, infrastructure learning, cloud concepts and future backend integrations.

## Purpose

The purpose of Baselarte is to serve as a continuous software engineering learning project, evolving from a static frontend application into a complete software system.

The project explores:

- frontend architecture;
- authentication systems;
- cloud storage;
- backend APIs;
- infrastructure;
- software design principles.

## Main Topics

- Software engineering
- Frontend development
- Web architecture
- Authentication and security
- Cloud computing
- Infrastructure
- Storage systems
- Programming practices

## Design Philosophy

The project follows a minimalist and functional approach:

- simple interfaces;
- efficient interactions;
- clear structure;
- maintainable code;
- progressive evolution without unnecessary complexity.

The goal is to prioritize functionality, clarity and usability.

## Current Features

Current frontend features include:

- Minimal landing page.
- SEO-oriented HTML structure.
- Responsive design.
- Dark mode synchronization.
- Login and registration interface.
- Frontend validation.
- Media upload interface.
- Image and video preview.
- Folder organization system.
- Media descriptions and hashtags.

Current data handling is performed in memory only.

Future versions will integrate backend services and persistent storage.

## Future Features

Planned features:

- User profiles.
- Mandatory @username system.
- Authentication with access and refresh tokens.
- Centralized API communication layer.
- Cloud storage integration.
- Media management using object storage.
- Secure password manager system.
- Continuous UX/UI improvements.
