01 — Practice

What we work on, in no particular hurry.

  1. i.

    Engineering

    Software that is correct first, fast second and clever only when it must be. Clear boundaries, honest abstractions, code meant to be read.

  2. ii.

    Infrastructure

    Cloud, storage and delivery treated as craft. Systems that are observable, reproducible and cheap to keep alive.

  3. iii.

    Interfaces

    Calm, legible, fast. Fewer screens, better words, motion with a purpose. The interface is the product people actually meet.

  4. iv.

    Creative technology

    Where engineering meets taste: experiments, tools and small instruments that make an idea tangible before it becomes a product.
