# Baselarte Magnolia

A minimalist landing page focused on software engineering, language and infrastructure.

## Features

- Responsive hero section
- SEO friendly HTML structure
- Light and dark theme support
- Theme preference saved with localStorage
- Animated quote transition between Portuguese and English
- Minimalist design with custom favicon

## Technologies

- HTML5
- CSS3
- JavaScript
- Docker
- AWS ECR
- AWS EC2

## Running

Open `index.html` in your browser.

No build tools or dependencies are required.

## Deployment

This project will be containerized with Docker and deployed on AWS using ECR and EC2.

## Theme

The website automatically remembers the user's preferred theme using browser localStorage.
